# 智慧台東：大目釋迦焚風預警與自動化防禦平台 - 釋迦守護者 (AIFoehn-Shield)

> **Demeter-01 智慧農業環境防禦系統**  
> 結合微氣象 AI 預測、果園 24H 監視器／手機短影音連續巡檢、自動噴霧降溫決策與 LINE 遠端推播，守護台東大目釋迦黃金產季。

---

## 📖 專案簡介

台東地區因中央山脈阻隔與地理環境特性，在特定季節（如西南氣流、颱風外圍沉降氣流）極易產生劇烈高溫且極度乾燥的「焚風」（Foehn Wind）。當氣溫飆升至 36°C 以上且相對濕度驟降至 30% 以下時，常導致即將採收的大目釋迦發生嚴重日燒、黑斑與落果。

**AIFoehn-Shield（釋迦守護者）** 專為解決小農外出、無法即時留守果園之痛點而設計：
1. **AI 焚風微氣象診斷與黃金 3 小時預警**：結合中央氣象署（CWA）預報與大武山背風側微氣象指標，提早 3 小時發出黃燈預警並自動執行蓄水池補水。
2. **自動化防禦決策**：超過 36.0°C 或高風險門檻時，自動連動高壓微霧降溫與迎風面防風網。
3. **🎥 24H 智慧果園監視器 & 手機實拍短影音連續巡檢（NEW!）**：支援上傳手機隨手錄製的 MP4 短片（如 7-11 香蕉實拍）或果園 CCTV 畫面，自動抽樣關鍵畫面（Keyframes）比對熟度、糖斑與日燒受損。
4. **LINE 官方帳號（@413asgvo）推播連動**：手機即時接收推播卡片，農友在市區或外出一鍵即可遠端控制降溫。
5. **多模態 AI 果實拍照辨識**：拍照分析釋迦／生鮮水果熟度、日燒受損等級與分級標價策略。
6. **台東黑熊守護員（小熊）AI 客服**：提供在地農友即時問答、歷史焚風實錄重演與防呆機制諮詢。

## 🌟 核心功能特色

- **微氣象監測與即時演算法**：支援台東各大產區（太麻里、知本、大武、卑南、東河）氣象參數輸入與即時推演。
- **中央氣象署 CWA 測站自動監測**：每 10 秒巡檢測站，當氣溫突破 36.0°C 自動連動發送警報。
- **24H 監視器 & 手機短影音 AI 連續巡檢**：
  - 擬真 CCTV 鏡頭螢幕 HUD（`REC 🔴`、時間戳、風速與環境數據疊加）。
  - 自動多幀抽樣（Keyframe Sampling）過濾手震。
  - 樹冠萎凋度、微霧覆蓋率（94.2%）與熟度黑斑連續診斷。
- **防呆安全機制**：
  - 低水位自動斷水保護（避免抽水馬達空轉燒毀）。
  - 防過濕病害計時器（10 分鐘自動倒數，防止濕度過高引發果腐炭疽病）。
  - 防重複推播鎖定機制。
  - LocalStorage 本地端 API Key 安全防護（保障個人額度安全不外洩）。
- **2026 臺東焚風實測事件時間軸**：收錄 2026 年重大焚風事件（含 10/24 成功鎮叭嗡嗡 39.3°C 極端峰值），支援一鍵重演實驗。

## 🚀 快速開始

本系統為純前端網頁應用（HTML5 + Tailwind CSS + Vanilla JavaScript），可直接在瀏覽器開啟：

1. 下載或複製本專案：
   ```bash
   git clone https://github.com/<your-username>/AIFoehn-Shield.git
   cd AIFoehn-Shield
   ```
2. 直接使用瀏覽器開啟 `index.html`。
3. 亦可直接部署至 **GitHub Pages** 免費對外公開。

- **LINE 機器人連動**：LINE Messaging API / Google Apps Script
